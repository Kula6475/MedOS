# MedOS

MedOS is an AI-powered emergency department operations platform that acts as an intelligent command center for clinicians. It helps physicians, nurses, pharmacists, and hospital administrators prioritize patients, surface safety risks, coordinate care, and turn fragmented clinical information into clear, auditable recommendations.

MedOS is a clinical decision support proof of concept. It does not diagnose patients, prescribe treatment, replace clinical judgment, or provide medical advice. All patient records used by the application are synthetic and must never be presented as real patient data.

> **Fireworks powers the intelligence; Braintrust builds trust.**

## Hackathon objective

The hackathon MVP will demonstrate one polished emergency-department workflow rather than attempt to reproduce an electronic health record. A user will select a synthetic high-risk patient, watch five specialized AI agents collaborate, and inspect the evaluation evidence attached to every recommendation.

Braintrust is the primary sponsor integration and the product's core differentiator. Every agent invocation will be traced, measured, evaluated, and made auditable through Braintrust. Fireworks AI is the LLM inference provider for every specialized agent.

## Specialized agents

### Triage Agent

Reviews symptoms, vital signs, arrival information, and clinical risk indicators. It proposes an emergency priority, identifies critical instability, and explains its findings using references to the supplied patient record.

### Medication Safety Agent

Reviews medications, allergies, relevant laboratory values, and proposed actions. It detects potential allergy conflicts, interactions, contraindications, and medication risks that require clinician or pharmacist review.

### Lab Analysis Agent

Summarizes abnormal laboratory findings, detects important trends, identifies missing or repeat tests for consideration, and highlights results requiring urgent clinical attention.

### Imaging Review Agent

Extracts the most important findings from radiology reports, identifies reported limitations, and connects imaging findings to the patient's current emergency-department presentation.

### Care Coordination Agent

Consumes the structured outputs of all specialist agents and produces a prioritized action plan organized into urgent, next, and monitor categories. It identifies unresolved risks and always requires human clinical review.

## Trust and observability

Each analysis run will create a Braintrust root trace with child spans for the specialist agents, Fireworks model calls, evaluations, tools, and the final safety gate. The MedOS interface will display:

- Evaluation status: pass, review, or blocked.
- Evidence-based system confidence.
- Agent latency.
- Model and prompt version.
- Trace availability.
- Missing information, limitations, and failed checks.

The displayed confidence is derived from evaluation results; it is not an unverified confidence number generated by the model. Recommendations that fail hard safety checks must be blocked or sent for explicit human review.

## Technology stack

- Next.js with the App Router.
- TypeScript.
- Tailwind CSS.
- shadcn/ui.
- Zod for structured agent contracts.
- Fireworks AI for LLM inference.
- Braintrust for tracing, evaluation, metrics, and observability.
- Server-Sent Events for visible agent progress.
- Static synthetic fixtures for the hackathon patient data.

The hackathon version does not require a production database, authentication system, real EHR connection, or real patient-data ingestion.

## Intended two-minute demo

1. **0:00–0:15 — Problem:** Emergency teams must make time-sensitive decisions from fragmented information, while black-box AI is unsuitable for high-trust clinical workflows.
2. **0:15–0:30 — Command center:** Show the MedOS patient queue, department status, alerts, and synthetic critical patient.
3. **0:30–1:10 — Agent run:** Open the patient workspace and start analysis. Show the Triage, Medication Safety, Lab Analysis, and Imaging Review Agents processing concurrently, followed by the Care Coordination Agent.
4. **1:10–1:40 — Trust evidence:** Reveal the coordinated action plan, evaluation status, confidence, latency, evidence references, and a Braintrust trace.
5. **1:40–1:55 — Safeguards:** Explain synthetic data, human review, blocked unsafe outputs, and the absence of autonomous clinical actions.
6. **1:55–2:00 — Close:** “Fireworks powers the intelligence; Braintrust builds trust.”

## MVP success criteria

- One click runs the complete five-agent workflow for the primary synthetic case.
- All LLM inference uses Fireworks AI.
- Every agent produces a Braintrust span with useful metrics and scores.
- The interface visibly transitions through processing and evaluation states.
- Every clinical claim includes valid evidence references.
- Unsafe, incomplete, or invalid outputs are blocked or marked for review.
- The deployed demo works in a clean browser and completes within the presentation window.
- A replay mode and recorded backup exist, and are clearly labeled as such.

## Safety statement

MedOS is an educational hackathon prototype using entirely synthetic data. It is not a medical device, has not been clinically validated, and must not be used to make decisions about real patients. Its outputs are clinical decision support for demonstration purposes only and are not medical advice.
